# 任务与数据术语

本文是任务中心、数据中心、API 和后续页面的统一用词依据。

## 一、对象边界

| 对象 | 用户理解 | 系统职责 |
|---|---|---|
| 任务 | 要执行的一件工作 | 采集、构建、检查、发布或计算 |
| 任务阶段 | 任务处于数据流程的哪一步 | 采集、构建、质量、发布、派生计算、维护 |
| 任务类型 | 任务具体做什么 | 源数据采集、标准数据构建、质量检查等 |
| 执行记录 | 某一次任务实际执行 | 状态、进度、周期、日志和错误 |
| 数据文件 | 任务产生或使用的文件 | Raw、候选、正式结果、报告等 |
| 数据版本 | 某个分区或结果的版本 | 当前版本、历史版本、回滚关系 |
| 指标定义 | 指标是什么以及如何计算 | 名称、口径、单位、关联任务 |
| 指标健康 | 指标结果是否更新和覆盖充分 | 最新周期、覆盖数量、覆盖率、状态 |
| 数据血缘 | 数据的来源和去向 | 上游输入、生成任务、下游使用 |

## 二、任务阶段

阶段只描述生命周期位置，不描述文件或运行记录。

| 内部值 | 用户名称 |
|---|---|
| `CAPTURE` | 数据采集 |
| `BUILD` | 数据构建 |
| `QUALITY` | 数据质量 |
| `PUBLISH` | 数据发布 |
| `DERIVED` | 派生计算 |
| `MAINTENANCE` | 数据维护 |

## 三、任务类型

| 内部值 | 用户名称 |
|---|---|
| `SOURCE_CAPTURE` | 源数据采集 |
| `DATA_BUILD` | 标准数据构建 |
| `QUALITY_CHECK` | 数据质量检查 |
| `DATA_PUBLISH` | 数据正式发布 |
| `INDICATOR_BUILD` | 技术指标计算 |
| `FACTOR_BUILD` | 研究因子计算 |
| `DERIVED_BUILD` | 派生数据计算 |
| `LEGACY_CONVERT` | 历史数据转换 |
| `DATA_REPAIR` | 数据修复 |

## 四、任务运行状态

数据库和 API 内部值保持英文，页面使用用户名称。

| 内部值 | 用户名称 |
|---|---|
| `requested` | 已请求 |
| `scheduled` | 已排期 |
| `waiting` | 等待执行 |
| `running` | 执行中 |
| `success` | 已完成 |
| `partial_success` | 部分完成 |
| `skipped` | 已跳过 |
| `failed` | 执行失败 |
| `cancelled` | 已取消 |
| `blocked` | 已阻断 |

## 五、数据产物

这些是技术产物，不是任务阶段。

| 内部值 | 用户名称 |
|---|---|
| `raw_batch` | 原始采集数据 |
| `candidate` | 待发布标准数据 |
| `quality_report` | 质量检查报告 |
| `published_dataset` | 正式数据 |
| `indicator_output` | 技术指标结果 |
| `factor_output` | 研究因子结果 |
| `diff_report` | 新旧结果差异报告 |
| `log` | 执行日志 |

`Raw Batch`、`Candidate`、`Quality Report` 和 `Published Version` 只在任务详情或技术详情中使用，不作为数据中心首屏分类。

## 六、数据中心分类

数据中心按用户关心的数据内容组织：

```text
基础行情
估值数据
基本面数据
技术指标
资金流指标
业务指标
研究因子
```

指标定义和指标健康是数据中心的主信息；任务、文件和血缘是关联信息。

## 七、禁止混用

- 阶段不是产物；
- 任务类型不是数据类型；
- 任务结果不是文件本身；
- `success` 只表示任务执行完成，不表示数据质量合格；
- `PASS` 只表示质量结论，不表示任务一定成功生成了正式版本；
- 指标定义不是指标结果；
- 指标健康不是任务状态；
- `Indicators` 和 `Factors` 是两个并列的派生计算任务，都直接依赖正式日线；
- Raw 文件不能称为正式数据；
- Candidate 不能称为当前数据；
- Shadow 发布只能称为“隔离验证发布”，不能称为生产正式发布。
